# 📱 DayToDay Wallet App

An intelligent, modern Progressive Web App (PWA) for daily expense tracking, financial savings goals, and smart bill scanning with arithmetic reconciliation.

---

## 🚀 Quick Start (Node.js)

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the App
```bash
npm start
```
The app will be available at:
* **Local Computer:** `http://localhost:8085`
* **Mobile (Same Wi-Fi):** `http://<YOUR_IP>:8085`

To run in development auto-reload mode:
```bash
npm run dev
```

### 3. Run Self-Tests
```bash
npm test
```

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Push this repository to your GitHub account.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select `Deploy from a branch`.
4. Choose `main` (or `master`) branch and folder `/ (root)`. Click **Save**.
5. Your live HTTPS app URL will be ready in 1-2 minutes!

---

## 📦 Convert to Android APK

1. Copy your live GitHub Pages link (e.g. `https://yourusername.github.io/wallet-app/`).
2. Go to **[PWABuilder.com](https://www.pwabuilder.com)**.
3. Paste your link and click **Start**.
4. Click **Package for Stores** → **Android (APK)**.
5. Download your signed APK and install directly on your phone!
